## Godot Platformer Game

A 2D platformer game developed collaboratively with a friend for a Panoply event at school during Class 11.

The game was built using the Godot Engine, with Git and GitHub used for version control and collaboration throughout development.

-->Features

* Multiple platforming levels
* Player movement and customized keybinds
* Character animations
* Combat and attack mechanics
* Enemy mobs
* Collectibles and currency
* Dialogue system
* Dynamic camera movement
* Parallax backgrounds
* Portals
* Main menu and intro sequence
* Level terrain and environmental elements

--> My Contributions

I contributed to several core gameplay and development systems, including:

* Implemented the basic player movement and keybind system
* Tuned player speed and gravity
* Added the main character sprite and animations
* Implemented dynamic camera movement
* Developed the collectibles/currency system
* Implemented the main menu functionality
* Added and implemented the dialogue system
* Developed the player attack/combat mechanic
* Worked on the intro sequence
* Developed and updated Level 1 terrain
* Added Easter eggs and environmental elements
* Implemented parallax backgrounds and portals
* Used Git/GitHub for collaborative development, merging, and version control

-->Technologies Used

* Godot Engine
* GDScript
* Git
* GitHub

# Project Background

This was one of my early software-development projects, created during Class 11 for a school Panoply event.

Working on the project introduced me to game development, programming with GDScript, version control, and collaborative software development. The repository preserves the original development history of the project.
